# MotoBan (MechBillerAI) — Official Brand Assets & Design System

Welcome to the official Brand Assets repository for **MotoBan** (powered by the **HybridStudioZ** engine). This folder contains all the official visual identity guidelines, logo vectors, color palettes, typography specifications, UI/UX design tokens, and print standards for the MotoBan platform.

---

## 📁 Directory Structure

```
brand-assets/
├── README.md                      ← You are here: Master index & overview
├── BRAND_GUIDELINES.md            ← Core brand identity, mission, voice & logo usage rules
├── COLOR_PALETTE.md               ← Digital (HEX/RGB/HSL) & Print (CMYK/Pantone) color system
├── TYPOGRAPHY.md                  ← Font pairings, scale hierarchy & letter spacing rules
├── UI_UX_DESIGN_SYSTEM.md         ← Component design tokens, glassmorphism & UX layouts
├── ICONS_AND_ILLUSTRATIONS.md     ← Iconography rules, stroke weights & mechanical motifs
│
├── logos/                         ← Master Vector Logos (SVG)
│   ├── motoban-logo-full-dark.svg     ← Primary horizontal logo (Void Black background)
│   ├── motoban-logo-full-light.svg    ← Primary horizontal logo (Light background)
│   ├── motoban-symbol-gradient.svg    ← Standalone "M" Turbo/Piston icon mark
│   ├── motoban-logo-monochrome.svg    ← Pure white monochrome version
│   ├── motoban-app-icon-512.svg       ← 512x512 PWA & mobile app icon
│   ├── motoban-powered-by-badge.svg   ← "Powered by HybridStudioZ" co-brand badge
│   └── motoban-flagship-partner.svg   ← "Verified at MotoFit 2" partner badge
│
├── palette/                       ← Visual Swatch Assets
│   ├── motoban-palette-preview.svg    ← Vector visual color swatch sheet
│   └── palette.json                   ← Design token variables (Figma, Penpot, Tokens Studio)
│
└── print-templates/               ← POS & Hardware Print Guidelines
    ├── 58mm-thermal-spec.md           ← 58mm (384-dot) thermal slip layout guide
    └── 80mm-thermal-spec.md           ← 80mm (576-dot) formal receipt layout guide
```
